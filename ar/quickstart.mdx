---
title: "البدء السريع"
description: "ابدأ بدليل يوضّح أسرع مسار للوصول إلى نتيجة ناجحة"
---

اشرح كيف يبدأ المستخدم في استخدام منتجك. ما أوّل شيء يحتاج إلى القيام به؟ وهل هناك أي متطلبات مسبقة؟

يجب أن ينقل دليل البدء السريع المستخدمَ من الصفر إلى استخدام منتجك فعلياً. سيحقّق نجاحاً سريعاً وسيكوّن فكرة عمّا يمكنه إنجازه.

## المتطلبات المسبقة

قبل أن تبدأ، يجب أن يتوفّر لديك:

- المتطلّب الأول (على سبيل المثال، Node.js 18 أو أحدث، حساب مجاني، مفتاح API)
- المتطلّب الثاني (على سبيل المثال، جهاز متوافق، متصفّح متوافق، نظام تشغيل متوافق)

## البدء

<Steps>
  <Step title="التثبيت">
    اشرح كيفية تثبيت منتجك أو التسجيل فيه.

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="التهيئة">
    اشرح أي إعداد أو تهيئة مطلوبة قبل الاستخدام الأول.

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="التشغيل">
    اعرض أوّل ما يفعله المستخدم لرؤية المنتج وهو يعمل.

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  وفّر للمستخدمين طريقةً للحصول على المساعدة. قد يكون ذلك رابطاً إلى صفحة الدعم، أو محادثةً مع وكيل دعم العملاء، أو منتدى خاصّاً بمنتجك.

  مثال: هل تحتاج إلى مساعدة؟ تواصل معنا عبر [support@yourcompany.com](mailto:support@yourcompany.com).
</Tip>
